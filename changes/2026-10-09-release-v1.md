# Report 2026-10-09: Release v1.0 — "Metal-Ready" 🎸

The desktop is complete, portable, and installable in one command.
This release marks the jump from VM to bare metal.

## What's in the box

**Desktop shell**
- Polybar pill bar with invisible top-row reserve bar
- Fullscreen-aware watcher v3 (hides only on real fullscreen; windows
  on the top strip never trigger it)
- Rofi: launcher (Super+Space), power menu, wallpaper picker with
  crossfade
- Hold-and-release Alt+Tab switcher (release Alt to commit, ~20ms) and
  classic Super+Tab switcher
- Plank dock (MaterialPill), picom compositor, update checker

**conky-glance widget**
- Date, weather (wttr.in, private local location), Spotify with
  clickable controls and progress
- Live 24-bar cava music spectrum while music plays
- Transparent, shadow-free, no icon-font glyphs (nothing renders as [])

**One-command install**
- `bash install.sh` does everything: package check (installs only
  missing, reports outdated, never upgrades silently), configs,
  xfconf settings (keybindings, stock panel off, margins), cava audio
  pinning, optional theme/icon extras
- Asks only for what's personal: weather location (stays in
  ~/.config/conky/location, never committed)
- Fully portable: no usernames or machine paths anywhere in the repo

## The journey (this release's highlights)

From the cava integration session through today: cava raw output was
binary by default; the awk bridge didn't split on ';'; the weather cache
used CPU-time instead of wall-clock and cached failures; the nerd-font
weather icon rendered as []; picom's shadow read as a border on the
transparent widget; the overlap watcher fired on any window touching
the top strip; XFCE keyboard shortcuts live under /commands/custom/,
not /custom/. Each fix is documented in the dated reports.

## Verification

- All scripts pass bash -n; install.sh is idempotent (re-runs skip
  installed packages and keep private files)
- Repo audit: zero hardcoded usernames/home paths; zip-code safety
  check in every push script; wallpapers and changes are the only data
  beyond configs

## Bare metal migration

    git clone https://github.com/lichtmeer/cachyOS-XFCE-dotfiles
    cd cachyOS-XFCE-dotfiles && bash install.sh

Then: log out/in, click the theme on (if the optional step was used),
clear saved sessions once, optionally theme LightDM. The verification
checklist in INSTALL.md walks the rest.

  `sed s|/home/userfolder|$HOME|g` in the autostart step (the .desktop files

## Addendum: sandbox install-test — two real bugs found and fixed

The one-command installer was tested end-to-end in a sandbox with
stubbed system tools (pacman, xfconf-query, pactl) against empty home
directories, simulating fresh machines, plus re-runs for idempotency.

### What the test verified
- Package step: missing packages installed in one pacman call with
  --needed --noconfirm; installed ones skipped (verified with a
  partially-installed machine: only the missing ones were touched).
- All keybindings set, including Super+< (wallpaper switcher) and
  Super+Space (launcher).
- All config files land in place; the verify step passes; exit 0.
- Re-running asks nothing again and keeps private files.
- Weather question: asked once, saved with spaces/umlauts intact,
  empty answer = IP auto-detect, never asked again once saved.

### Bug 1: personal path still in the autostart step
The earlier audit script claimed to remove the `sed s|/home/userfolder|$HOME|g`
line from install.sh, but its sed command failed silently (delimiter
collision with the | characters in the pattern) and the line survived.
Replaced with a plain `cp` — the .desktop files are already portable.

### Bug 2: the weather question never existed
The docs promise the installer asks for a weather location "only if
~/.config/conky/location is missing" — but conky/install.sh contained
no such question. Fresh installs silently fell back to IP detection
and never saved the location. Added the question before the cava
pinning step; the file stays private and is never committed.

Both fixes were re-tested twice in the sandbox (second run applied the
exact patch blocks from the release script to a fresh clone):
location written on first run, kept on re-run, question not asked
again.
