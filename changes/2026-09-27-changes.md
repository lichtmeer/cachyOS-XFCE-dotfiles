# Report 2026-09-27: Polybar Desktop Shell on CachyOS XFCE

## What we built today

Starting from a fresh CachyOS + XFCE install, the desktop is now a full
Polybar-based shell:

1. **Polybar replaced the XFCE panel** - a floating, rounded "google-top"
   pill, centered at the top, in Google Material You dark colors. The XFCE
   panel is blocked at the session level, so it never comes back.
2. **Design** - 66% width, Material dark palette (#1C1B1F surface, #A4C3FF
   blue accent), Nerd Font icons for disk, volume, RAM, CPU, a GNOME-style
   dot workspace indicator, and an IEC power-symbol logout button that
   calls xfce4-session-logout.
3. **Transparency done right** - picom compositor with the GLX backend;
   the black corner artifacts were fixed by turning polybar's
   pseudo-transparency off.
4. **Windows never go behind the bar** - an invisible full-width helper bar
   ("struthelper") reserves the entire top row; a watcher script hides the
   pill if a window is dragged over it, and on F11 fullscreen. Maximized
   windows stop below the bar with a small gap.
5. **Screen-edge gaps** - 8px margins on left/right/bottom so maximized
   windows never touch the screen edges (via xfwm4 margins).
6. **Rofi launcher** - Ribbon Top Round layout recolored to match the bar:
   pixel-aligned with the pill (1251px wide, 8px below the bar), solid dark
   background, uniform grid, blue-outline selection, toggled by Super+Space.

## Where the files are

| File | What it is |
|---|---|
| ~/.config/polybar/config.ini | The polybar config: colors, the pill bar, all modules, the invisible struthelper bar |
| ~/.config/polybar/launch.sh | Starts both polybar bars (kills old ones first, waits for clean shutdown) |
| ~/.config/polybar/hide-when-overlapped.sh | The watcher: hides/shows the pill when windows overlap it or go fullscreen; logs to /tmp/polybar-hide-debug.log |
| ~/.config/rofi/config.rasi | The rofi launcher: Ribbon layout, colors, geometry, Super+Space close key |
| ~/.config/picom/picom.conf | Compositor config (GLX backend, shadows, fading) |
| ~/.config/autostart/polybar-watcher.desktop | Autostart entry for the watcher script |

Also relevant, but not part of the dotfiles: ~/.icons/YAMIS/ is the
installed monochrome icon theme (re-downloadable, not backed up).
The old ~/.config/rofi/toggle.sh was deleted - obsolete.
/tmp/polybar-hide-debug.log is just a log; never back it up.

## Settings that live outside files (xfconf / session storage)

GitHub will NOT save these. Note them for a fresh install:

- xfce4-session: Failsafe Client2_Command -> /bin/true (blocks the panel)
- xfce4-panel: /panels -> 0
- xfwm4: margins - left 8, right 8, bottom 8, top 0
- Keyboard shortcut: Super+Space -> rofi -show drun
- Autostart entries (Settings -> Session and Startup): one for launch.sh,
  one for picom -b, one for the watcher
- Saved sessions cleared (so the watcher does not start twice)

## Bugs found and fixed along the way (worth remembering)

- XFCE panel kept returning: fixed by pointing the failsafe session's
  Client2_Command at /bin/true and clearing saved sessions.
- Black corners on the pill: picom + polybar pseudo-transparency conflict;
  pseudo-transparency must be false when a compositor runs.
- Workspace dot warning "Dropping unmatched character": the dot glyph is
  missing from Noto Sans and Symbols Nerd Font; fixed by adding
  Noto Sans CJK TC as font-2.
- Overlap watcher initially grabbed the wrong window ID (trailing 0x0 in
  _NET_ACTIVE_WINDOW output); fixed by grepping the first hex ID.
- polybar-msg cmd hide is a broadcast that hit the helper bar too;
  fixed by targeting the pill PID explicitly (-p).
- Polybar removes struts when hidden and rejects empty-module bars;
  fixed with a dummy single-space module in the helper bar.
- Rofi every-second-row yellow stripes: rofi's built-in fallback theme
  paints alternate rows cream; only full-state selectors
  (element normal.normal / alternate.normal) override it.
- Rofi Super+Space would not close an open rofi: rofi grabs the whole
  keyboard, so the key never reached XFCE; fixed by adding Super+space
  to rofi's own kb-cancel key.

## Wallpaper picker with previews + crossfade

- `rofi/wallpaper.sh` -> `~/.config/rofi/wallpaper.sh`
  - Rofi dmenu picker listing everything in `~/Pictures/wallpapers`
  - Small image previews next to each entry (96x54 thumbnails, cached in
    `~/.cache/wallpaper-thumbs`, regenerated automatically when a file changes)
  - Escape = cancel, nothing changes
- `rofi/wallpaper-fade.sh` -> `~/.config/rofi/wallpaper-fade.sh`
  - Smooth crossfade when switching wallpapers (no hard cut)
  - Blends old -> new in 9 steps using ImageMagick, then sets the final
    wallpaper at full resolution
  - Blend frames are rendered at half HD as JPG for speed (about 8x faster
    than full-size PNG; invisible during a sub-second fade)
  - Tuning knobs at the top of the script: `FRAMES` (smoothness),
    `STEP` (delay per frame = fade duration)
  - Temporary frames live in `~/.cache/wallpaper-fade` and are cleaned up
    after each fade - throwaway runtime data, never commit them
  - Only one fade at a time (flock); switching to the current wallpaper
    or a missing file is handled instantly/silently

Dependencies: `imagemagick` (thumbnails + blend frames), `rofi`,
`libnotify` (optional, for the error popups).

Note: fade smoothness is limited in a VM (virtual GPU); on real hardware
it renders cleaner.

## Plank dock (replacing cairo-dock attempt)

- Tried cairo-dock first: works but its OpenGL rendering made the VM
  noticeably slow; removed again in favor of Plank.
- `plank/dock.theme` -> `~/.local/share/plank/themes/MaterialPill/dock.theme`
  - Custom "MaterialPill" theme matching the polybar pill: surface
    #1C1B1F flat fill, rounded ends (18px), thin #2A2930 stroke,
    badge color = accent #A4C3FF.
  - Plank theme files are plain keyfiles; note that comment lines must
    stay intact - a split `#` comment line makes Plank refuse the file.
- `autostart/plank.desktop` -> `~/.config/autostart/plank.desktop`
  - Starts Plank on login, no terminal window.
- Verified on re-login: dock starts, everything else (polybar, picom,
  watcher) unaffected.

Dependencies: `plank` (sudo pacman -S plank).

## LightDM GTK greeter themed to match the desktop

- The greeter runs as a system user before login, so it cannot see
  themes in ~/.themes - user-side themes are invisible to it.
- Fix: copied the theme system-wide:
    sudo cp -r ~/.themes/Orchis-Dark /usr/share/themes/
- Then set in /etc/lightdm/lightdm-gtk-greeter.conf, [greeter] section:
    theme-name = Orchis-Dark
    icon-theme-name = Adwaita
    font-name = Noto Sans 11
    background = #1C1B1F
- Verified: login screen now uses the dark theme.
- Revert (if ever needed): remove the theme-name/background lines from
  the conf file and optionally delete /usr/share/themes/Orchis-Dark.
