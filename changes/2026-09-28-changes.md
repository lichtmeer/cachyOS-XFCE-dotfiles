
## Power menu: restart/shutdown showed the XFCE logout manager

- Bug: "Yes, restart" in the rofi power menu opened the xfce4-session
  logout dialog instead of rebooting.
- Root cause: the script used `--restart`, which is not a valid option
  of xfce4-session-logout - invalid options are ignored, so the command
  fell back to its default behavior (showing the logout manager).
- Fix: use the correct options from the man page: `--reboot` (restart)
  and `--halt` (shutdown), both of which act immediately without any
  dialog. The rofi-side confirmation ("Restart now?") is unchanged.
