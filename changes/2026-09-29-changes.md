# Report 2026-09-29: Window transparency for all apps (games excluded)

## What we built today

All windowed apps are now slightly see-through (90% opacity), while
fullscreen apps - games above all - stay fully solid.

- `active-opacity = 0.90` - the focused window
- `inactive-opacity = 0.90` - every other window
- `fullscreen-opacity = 1.0` - any true fullscreen window is forced back
  to fully solid, so games and fullscreen video are never transparent

Both window types use the same value on purpose: a uniform look, no
flicker of opacity change when switching focus.

## Where the files are

| File | What it is |
|---|---|
| picom/picom.conf | Compositor config; transparency lines appended at the end |

The live config (~/.config/picom/picom.conf) was edited with a small
bash helper script; the change is identical to what this repo now tracks.

## Settings that live outside files

Nothing new - all changes are in picom.conf, which the repo already
tracks. XFCE's own compositor stays disabled as before (Window Manager
Tweaks -> Compositor -> "Enable display compositing" must remain
unchecked; picom is the only compositor).

## Bugs found and fixed along the way (worth remembering)

- `picom --replace` does not exist in picom v13 - the option was
  removed. Restart picom with `killall picom; picom -b` instead.
- A first paste of the helper script into an interactive bash shell
  produced syntax errors; scripts must be saved to a file and run with
  `bash <file>`, never pasted line-by-line into a prompt.
- The same broken paste partially executed and appended stray lines to
  the live picom.conf; fixed by re-running the clean script and
  checking with `grep opacity ~/.config/picom/picom.conf` (exactly
  three lines expected).

## Known caveats

- A game running in borderless-windowed mode instead of true fullscreen
  is not detected as fullscreen and would still get transparency.
  If that ever matters, force the game solid with an opacity-rule:
      opacity-rule = [ "100:class_g = 'NameOfGame'" ];
- Transparency costs a little GPU; on very weak hardware dragging
  windows may feel less smooth. If so, remove the opacity lines.
