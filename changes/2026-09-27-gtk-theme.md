# Report 2026-09-27: GTK Theme (Orchis Dark)

## What was added

The GTK theme "Orchis" (Material Design) by vinceliuice, dark variant with
the default blue accent, applied to the whole desktop to match the
Material You dark polybar design.

## What it covers

- App contents (menus, buttons, sliders) - via Appearance settings
- Window title bars - via Window Manager settings
- Not pixel-perfect: Orchis's blue accent is close to the bar's #A4C3FF
  but not identical. OOMOX/Themix could repaint it exactly if needed later.

## How to restore on a fresh install

    git clone https://github.com/vinceliuice/Orchis-theme.git ~/Orchis-theme
    ~/Orchis-theme/install.sh --theme default --color dark
    rm -rf ~/Orchis-theme

Then apply manually:

1. Settings -> Appearance -> Style -> Orchis-Dark
2. Settings -> Window Manager -> Style -> Orchis-Dark

## Where it lives on disk

~/.themes/Orchis-Dark (created by the install script; not backed up in
this repo since it is re-downloadable).
